Java & memory

Each group follows the global default until you override it, so changing a default later still reaches every instance that never disagreed with it.

Duplicate

Copies the mod list and configs under a new name. Costs almost nothing on disk, since mods are shared from one store — so it is a cheap way to try a change without risking the instance you actually play.

Export

Writes a zip containing the mod jars themselves, not just a list of them, so it is useful on a machine that has never seen this one.

Delete this instance

The mod files stay in the shared store and the history is kept, so this can be undone until you prune.
